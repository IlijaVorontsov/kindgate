    One-time set-up, then a button appears on the morning page:

    Kindgate sends one thing: the minutes to wait (e.g. 90) as Shortcut Input. Everything else — timer or reminder, the alert, the date maths — lives in the shortcut.

    Easiest build — a timer. One action: Start Timer for Shortcut Input minutes. The duration field takes a number straight away, with no date to wrestle.

    If you want a reminder: putting Shortcut Input straight into At Time fails with “couldn’t convert from Text to Date” — the input is text, and that field needs a date. Something has to make a date first:

    1. Add an Adjust Date action above the reminder. Set it to: add Shortcut Input Minutes to Current Date. This is the missing piece — it outputs an Adjusted Date.
    2. In Add New Reminder, tap the At Time field and put Adjusted Date in it — not Shortcut Input.
    3. Take Shortcut Input out of the reminder’s title, unless you want “90” in the text.
    4. Type the shortcut’s exact name above.

    The rule: Shortcut Input is text. Only Current Date and Adjust Date produce real dates, and only a real date works in that field.

    Or just ask Siri “set a timer for 90 minutes”. Only the Shortcuts app has a documented URL scheme; Clock and Reminders don’t, so this is the supported route.

    This runs the whole shortcut, so read the outcome carefully:
    • Shortcuts says it can’t find it → the name is wrong.
    • Shortcuts opens and shows an error → the name is right; the actions inside need fixing.
    • A timer or reminder appears → done.

    Your own shortcuts

    Every Optional link field in Kindgate — morning steps, evening plans, wind-down audio — accepts a shortcuts:// link. So any button here can run a shortcut of yours: start a timer, set a reminder, play a playlist, turn on a Focus, log to a note.

    Build the link, copy it, paste it into whichever field you want:

    In the shortcut, use Shortcut Input wherever you want that value to land. Name it something short and unmistakable — the link matches on the name, so renaming it later breaks the link.

    Made one worth keeping? In Shortcuts, tap ⋯ → Share → Copy iCloud Link, and paste it here so it’s one tap to reinstall — on a new phone, or for anyone you pass this extension to.

    Nothing in this extension is sent anywhere. All data lives in the extension’s storage on this phone.
